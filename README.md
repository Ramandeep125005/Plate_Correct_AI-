# 🥗 Plate Correct AI
Plate Correct AI is an AI-powered web application that provides personalized nutrition guidance through health assessments and food recommendations.

## ✨ Features
- User Registration & Login
- Health & Diet Assessment
- AI-Based Nutrition Suggestions
- Personalized Dashboard
- Responsive UI

## 🛠️ Tech Stack
- React + Vite
- Supabase
- OpenAI API


This project is developed for educational purposes only.
